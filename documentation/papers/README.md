# Paper References

This directory contains metadata-only reference entries for papers used in MEOGAP. Do not commit PDFs or full-text copyrighted papers.

## Organisation

- `products/` — geoproduct references, for example [land](products/land.md) and [water](products/water.md).
- `indicators/` — monitoring-indicator references, to be added as indicator work is refined.
- `methods/` — cross-cutting method references such as machine learning, to be added when needed.
- `local_ref/` — local PDF copies, gitignored and never committed; this directory mirrors the subject structure.

Each reference entry must include the title, authors, year, journal or venue, DOI or canonical URL, a short description of relevance, and limitations or notes. Documentation must link to the reference entry or DOI, never to a local PDF.

See [`agents/REPOSITORY_RULES.md`](../../agents/REPOSITORY_RULES.md) for the authoritative repository policy.
